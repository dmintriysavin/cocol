# Учебный репозиторий ДГТУ

Данный репозиторий предназначен для хранения лабораторных и практических работ.

## Дисциплины

- Git и GitHub
- Программирование
- Информационные технологии

## Правила ведения репозитория

1. Каждая дисциплина хранится в отдельной папке.
2. Файлы должны иметь понятные названия.
3. Изменения фиксируются с помощью commit.
4. Для новых задач используются отдельные ветки.
5. Важные изменения сопровождаются комментариями.
